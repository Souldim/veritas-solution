VERITAS PROJECT MANAGER

INSTALLATION
1. Copy admin.html into the root folder:
   Documents/GitHub/veritas-solution/
2. In GitHub Desktop:
   Summary: Add project manager
   Commit to main
   Push origin
3. Open:
   https://souldim.github.io/veritas-solution/admin.html

HOW IT WORKS
1. Select the current projects.json.
2. Fill in project information.
3. Select Before, Progress, and After photos.
4. Click "Создать ZIP проекта".
5. Unzip the downloaded package.
6. Copy its project folder into veritas-solution/projects.
7. Replace the root projects.json.
8. Commit and Push using GitHub Desktop.

IMPORTANT
- The page works locally in your browser and does not receive your GitHub password.
- It cannot publish automatically because GitHub Pages is a static free host.
- It prepares all files and JSON automatically; you only copy them and Push.
