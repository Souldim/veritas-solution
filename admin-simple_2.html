Veritas Project Publisher

Описание + фото ДО + фото ПОСЛЕ. Перевод EN / ES / UK создаётся автоматически.

1. Подключение к GitHub

По умолчанию токен не сохраняется. Если поставить галочку «Запомнить токен», Opera сохранит его локально на этом компьютере.

2. Описание работы AUTO TRANSLATE

Ты пишешь только по-английски. Перед публикацией страница автоматически создаст испанскую и украинскую версии. Если перевод не сработает, проект НЕ будет опубликован.

3. Фотографии

ДО работы

Добавь одно или несколько фото до начала работы.

ПОСЛЕ работы

Первое фото в этом блоке станет главным фото проекта.

4. Опубликовать

Будет создан один Git-коммит: фотографии, info.json и обновлённый projects.json.
