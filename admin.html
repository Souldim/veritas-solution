Veritas Project Manager

Создание проекта с фотографиями «до / процесс / после» без ручного редактирования JSON.

1. Загрузить текущий projects.json

Файл находится в корневой папке veritas-solution. Страница добавит новый проект и создаст обновлённую копию.

2. Информация о проекте

3. Фотографии

До работы

Будут названы: before1.jpg, before2.jpg…

В процессе

Будут названы: progress1.jpg, progress2.jpg…

После работы

Первое фото станет hero.jpg, остальные — after2.jpg, after3.jpg…

4. Создать готовый пакет

Что будет внутри ZIP

  • папка проекта с переименованными фотографиями;
  • info.json внутри папки проекта;
  • готовый обновлённый projects.json;
  • короткая инструкция.

Как использовать готовый ZIP

  1. Распаковать ZIP.
  2. Скопировать папку проекта внутрь veritas-solution/projects.
  3. Заменить корневой projects.json файлом из ZIP.
  4. GitHub Desktop → Commit to main → Push origin.
